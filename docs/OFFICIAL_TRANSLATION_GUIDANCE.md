# Official SPICT translation guidance - project summary

Source: the SPICT Translations page text supplied by the project owner on 2026-09-07.

For a first translation into a new language, the page says in substance:
- use an evidence-based translation/cross-cultural adaptation approach;
- use a multidisciplinary team and record the process clearly;
- usually begin with a small group with palliative-care experience;
- share the initial translation with a wider group for peer review;
- after edits, try it in clinics/wards;
- groups from the same country/language should work together;
- a final version can be shared with the SPICT international community;
- the SPICT team may help with PDF layout if needed.

The page explicitly offers the 2026 SPICT-4ALL Word translation template and points to WHO, Beaton, and TRAPD methods.
